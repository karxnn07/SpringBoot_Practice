## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Java JDK 17 or later, compatible with the project
- Apache Maven
- IntelliJ IDEA or another Java IDE
- Git

### Clone the Repository

```bash
git clone https://github.com/karxnn07/SpringBoot_Practice.git
cd SpringBoot_Practice
```

### Open and Run a Project

1. Open the required project or module in IntelliJ IDEA.
2. Allow Maven to import dependencies.
3. Verify the configured JDK and Maven settings.
4. Locate the main application class.
5. Run the class and check the console output.

For Maven-based projects, you can also use:

```bash
mvn clean install
```

Run this command from the relevant Maven project directory.
